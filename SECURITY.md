**# Security Policy

## Supported Versions

Only the latest version deployed on the production instance is currently supported and monitored for security updates.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

We take the security of **FinFlow** seriously. If you discover a security vulnerability, please do **NOT** open a public GitHub issue.

### How to report:
1. Contact the project maintainer directly via **Direct Messages**:  
   [![Discord](https://img.shields.io/badge/Discord-5865F2?style=flat-square&logo=discord&logoColor=white)](https://discord.com/users/874571768369664051)
2. Provide a detailed description of the issue and steps to reproduce the vulnerability (Proof of Concept).

### Response Timeline:
- **Initial Response**: Within 24–48 hours.
- **Fix & Deployment**: Critical issues will be patched and deployed to production as soon as possible.

Thank you for helping keep FinFlow and its users safe!**
